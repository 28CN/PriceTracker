==============================
PriceTracker 本地定时任务说明
==============================

任务名称：PriceTracker - Weekly
执行时间：每周一、每周三 早上 06:00
作用：本机全量爬价（含 GitHub CI 爬不到的店）
日志位置：d:\Programming\Practice for job\PriceTracker\logs\crawl-YYYYMMDD.log

漏跑补跑（开机/唤醒后）：
  - 仍会补跑，但不会在开机瞬间抢 CPU/内存
  - 系统空闲约 8 分钟后才允许启动
  - 脚本再等开机满约 20 分钟才打开 Chrome
  - 以 Idle / 最低计划优先级运行，可边用电脑边爬
  - 允许最长跑 2 小时

紧急调试（跳过开机等待）：
  $env:CRAWL_BOOT_GRACE_MINUTES = "0"
  powershell -ExecutionPolicy Bypass -File scripts\crawl-background.ps1


==============================
如何查看任务是否在运行
==============================

方法一：打开"任务计划程序"
  1. 按 Win+S，搜索"任务计划程序"，打开
  2. 左侧点"任务计划程序库"
  3. 找到"PriceTracker - Weekly"，查看状态和上次运行时间

方法二：PowerShell 命令
  Get-ScheduledTask -TaskName "PriceTracker - Weekly"
  (Get-ScheduledTaskInfo "PriceTracker - Weekly").NextRunTime


==============================
如何手动立刻跑一次
==============================

双击或在 PowerShell 里运行：
  powershell -ExecutionPolicy Bypass -File scripts\crawl-local.ps1


==============================
如何暂停定时任务（暂时停用）
==============================

方法一：任务计划程序里右键 → 禁用
方法二：PowerShell 命令
  Disable-ScheduledTask -TaskName "PriceTracker - Weekly"

恢复：
  Enable-ScheduledTask -TaskName "PriceTracker - Weekly"


==============================
如何永久删除定时任务
==============================

方法一：任务计划程序里右键 → 删除
方法二：PowerShell 命令（复制粘贴到 PowerShell 回车即可）
  Unregister-ScheduledTask -TaskName "PriceTracker - Weekly" -Confirm:$false

删除后如果想重新注册，以管理员身份运行：
  powershell -ExecutionPolicy Bypass -File scripts\register-tasks.ps1


==============================
如何修改执行时间
==============================

1. 打开任务计划程序
2. 找到"PriceTracker - Weekly"，双击
3. 切换到"触发器"标签，双击要修改的触发器
4. 修改时间后点确定保存
